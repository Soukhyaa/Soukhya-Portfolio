## About

This is a single-page portfolio site introducing Soukhya, listing core skills, and providing direct contact links (email + GitHub). Built with plain HTML, CSS, and JavaScript — no frameworks or build tools required.

## Tech stack

- **HTML5** — page structure
- **CSS3** — custom properties (design tokens), responsive grid/flex layout
- **JavaScript (vanilla)** — typing-terminal animation in the hero section

## Project structure

```
portfolio/

├── README.md        → this file

└── RND.md            → R&D notes: design tokens, layout plan, build decisions
```

## How to view it

**Option 1 — Open directly**
Just double-click `index.html`, or open it in any browser.

**Option 2 — Host it for free**
1. Create a new GitHub repo (e.g. `portfolio`) under [github.com/Soukhyaa](https://github.com/Soukhyaa).
2. Upload `index.html` to the repo.
3. Go to **Settings → Pages**, set the source branch to `main`, and save.
4. Your site will be live at `https://soukhyaa.github.io/portfolio/` within a few minutes.

You can also drag-and-drop the folder into [Netlify Drop](https://app.netlify.com/drop) or [Vercel](https://vercel.com) for an instant live link.

## Customizing

- **Colors** — edit the CSS custom properties at the top of the `<style>` block in `index.html` (`--bg`, `--accent`, etc.).
- **Copy text** — hero headline, about paragraph, and terminal roles are plain text/JS in `index.html`; edit directly.
- **Adding projects** — once you have projects to show, add a new `<section id="projects">` between Skills and Contact, following the same card pattern used in the Skills section.
